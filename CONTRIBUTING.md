# Contributing to mic thingy

Thanks for helping! Bug reports, Linux test results, translations and code are all welcome.

## Getting started

1. Build and run the tests (see [README.md](README.md#building)): `ctest --test-dir build` must pass.
2. Read [CLAUDE.md](CLAUDE.md) - it is the developer handbook: architecture, real-time rules, test tools,
   measured numbers and the reasons behind the defaults.

## Ground rules

- **Real-time safety.** Code that runs in the audio callback (`engine_process_block`, `pipeline_process`,
  every `Fx.process` / `set_param`, sink reads/writes) must not allocate, lock, print or do I/O.
  Allocate in `init`, free in `destroy`; pass parameters through atomics, meters through the ring buffer.
- **C11, warning-free.** Our code builds with `-Wall -Wextra -Wpedantic` without warnings
  (third-party code is compiled with `-w`).
- **Tests for behaviour changes.** DSP and engine changes get a check in `tests/test_dsp.c`
  (signals generated in C, cross-platform). Sound-quality changes should be measured with the audio
  matrix (`tools/make_testset.ps1`, `tools/run_audio_tests.ps1`) and the numbers quoted in the PR.
- **Both languages.** Every new UI string goes into `src/app/i18n.c` in English and Polish
  (a test fails on empty entries).
- **On/off controls** use `onoff()` in `src/main_gui.c` (green = on, burgundy = off).
- **Third-party code** stays in `third_party/`; local changes are documented (e.g. `third_party/rnnoise/PATCHES.md`)
  and new dependencies must have a permissive, MIT-compatible license added to
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- **Artwork**: the icon and logo are generated by `src/app/icon_art.c`; after changing it run
  `build/make_icon assets/mic-thingy.ico assets/logo-1024.png assets/logo-256.png` and commit the outputs.

## Adding a translation

Add a value to `VfLang` in `src/app/i18n.h`, a column to every table in `src/app/i18n.c`
(UI strings, effect titles, parameter labels), preset display names in `src/app/settings.c`,
and the language code to the EN/PL toggle in `src/main_gui.c`.
